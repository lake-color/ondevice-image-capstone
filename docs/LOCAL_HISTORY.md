# 로컬 분석 이력

## 저장 형식

`path_provider`의 앱 지원 디렉터리에 `analysis_history.json`을 저장합니다.
JSON 최상위에는 `version: 1`과 최신순 `entries` 목록을 둡니다.
각 항목은 고유 ID와 분석 결과를 포함하며 원본 이미지 바이트나 경로는 저장하지 않습니다.
동일 시각의 결과도 ID에 접미사를 붙여 독립적으로 삭제할 수 있습니다.

## 실패 처리

- 읽기·형식 검증 실패 시 파일을 유지하며 이력 화면에 재시도 버튼을 표시합니다.
- 알 수 없는 버전 또는 잘못된 항목이 있으면 전체 로드를 중단합니다.
- 로드하지 못한 상태에서는 기존 이력을 덮어쓰지 않습니다.
- 저장·삭제 작업은 순서대로 수행하며 디스크 기록 성공 후 화면 상태를 갱신합니다.
- 임시 파일을 flush 후 교체합니다. 중단된 임시 파일은 다음 저장 시 다시 작성합니다.
- 저장 실패 시 OCR 결과를 화면 상태에 유지하고 OCR을 반복하지 않고 저장을 재시도합니다.
- 앱 삭제·데이터 초기화에 대한 복구나 기기 간 동기화는 지원하지 않습니다.

## 검증 범위

자동 테스트는 실제 임시 디렉터리를 이용한 재로드·삭제·전체 삭제, 동일 시각 ID,
한글 및 결과 필드 왕복, 저장 실패 시 원본 유지, 손상 데이터 보호, 읽기 재시도를 다룹니다.
실제 Android/iOS 앱 재실행과 OCR 입력·권한 흐름은 기기에서 별도로 검증해야 합니다.

공식 패키지 문서: https://pub.dev/packages/path_provider
