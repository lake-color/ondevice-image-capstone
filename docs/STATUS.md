# 진행 현황

기준일: 2026-11-02. 현재는 **핵심 기능 구현 후 검증·안정화 단계**입니다.
현재 코드, 기존 검증 문서, 이 프로젝트에 해당하는 과거 세션을 대조해 정리했습니다.

## 구현 상태

| 기능 | 상태 |
|---|---|
| UI | 시작·사진 선택·로딩·결과·이력 화면 구현 |
| 입력 | 카메라·갤러리 연결, 미리보기와 권한 오류 안내 |
| 사물 분류 | 내장 MobileNetV3 실제 추론, 클래스명·신뢰도 표시 |
| OCR | 한국어 ML Kit 모델로 한글·영어 인식 |
| 결과 | 원본 미리보기, 처리 시간, 텍스트·신뢰도, 클립보드 복사 |
| 이력 | 로컬 JSON 저장·조회·개별 삭제, 재로드, 읽기·저장 재시도 |
| 동기화 | Firebase 인증·기기 간 동기화 미구현 |
| 제출물 | `submission/PRIVACY.md`, `submission/prompts_log.md` 모두 빈 파일, 작성 필요 |

## 검증 기록

아래 과거 기록은 이번 문서 정리에서 재실행한 결과가 아닙니다.

| 시점 | 확인 범위와 결과 |
|---|---|
| 2026-10-25 초기 UI | Android 에뮬레이터에서 시작·사진 선택·빈 이력 화면과 디버그 빌드 확인 |
| 2026-10-27 기존 기록 | 정적 분석, 단위·위젯 14개, Android 네이티브 분류 통합 테스트 1개 통과 |
| 2026-10-30 기존 기록 | 공개 사진 분류와 선명한 한영 OCR 검사. 사과 분류는 실패, 혼합 OCR은 통과 |
| 2026-11-02 구조 정리 | 정적 분석 및 단위·위젯 테스트 18개 통과. 이동된 이미지 경로도 위젯 테스트에서 사용 |

10월 30일 Pixel 9 Pro Android 에뮬레이터의 사진 검증 기록:

| 입력 | 출력 | 신뢰도 | 결과 |
|---|---|---|---|
| [고양이](https://commons.wikimedia.org/wiki/File:Cat03.jpg) | Egyptian cat | 31.1% | 고양이 계열 인식, 품종은 미검증 |
| [빨간 사과](https://commons.wikimedia.org/wiki/File:Red_Apple.jpg) | pomegranate | 78.9% | 석류로 오분류 |

사진 두 장은 정확도 평가 데이터셋이 아닙니다. 높은 softmax 점수도 정답을 보장하지 않습니다.
같은 품질 테스트에서 생성한 `안녕하세요`, `사과와 고양이`, `Hello World 123`은 인식했으나,
흐림·손글씨·실제 촬영 문서의 정확도는 별도 평가가 필요합니다.

## 남은 작업

1. 대표 사진으로 분류 정확도를 평가하고 모델 교체·학습 여부 결정.
   빨간 사과 정답을 요구하는 품질 테스트는 기존 기록상 실패 상태입니다.
2. 통합 테스트 이동 후 `flutter drive`로 기기 테스트 재실행.
   일반 `flutter test` 통과는 네이티브 OCR·분류 검증을 의미하지 않습니다.
3. 실기기에서 촬영·갤러리·권한 거부·연속 분석·앱 재실행 후 이력 유지 확인.
   iOS는 macOS에서 빌드와 인식·권한 동작 검증이 필요합니다.
4. 권한 안내의 ‘설정에서 권한 열기’ 버튼을 실제 설정 이동에 연결.
   현재 버튼은 대화상자만 닫습니다.
5. 분석 취소 동작 보완 여부 결정. 현재는 화면을 닫고 후속 UI 처리를 막으며,
   진행 중인 네이티브 추론 자체를 중단하는 기능은 없습니다.
6. 현재 구현 기준으로 전체 화면의 디자인·작은 화면·한글 폰트 확인,
   제출용 개인정보 문서와 프롬프트 기록 작성.

Firebase 동기화와 OS 공유창 연결은 필요에 따라 진행할 확장 항목입니다.
실행 명령과 테스트별 범위는 [테스트 안내](../test/README.md)를 참고하세요.
