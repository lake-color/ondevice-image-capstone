# 사진 분석 앱

사진을 촬영하거나 갤러리에서 선택한 뒤, 기기 내에서 이미지를 분석하고  
결과를 확인할 수 있는 Flutter 기반 모바일 앱 프로젝트입니다.

고급 모바일 프로그래밍 수업 과제 **#2107 사진 분석 앱**을 바탕으로 진행하고 있습니다.

## 프로젝트 소개

사용자가 원하는 사진을 선택하면 온디바이스 AI를 이용해 사진을 분석하고, 분석 결과를 확인할 수 있는 앱을 목표로 합니다.

분석은 서버가 아닌 스마트폰 내부에서 처리하며, 원본 사진은 분석 이력에 저장하지 않고 분석 결과만 저장하는 방향으로 개발합니다.

## 주요 기능

프로젝트에서 구현할 주요 기능은 다음과 같습니다.

* 카메라를 이용한 사진 촬영
* 갤러리에서 사진 선택
* 선택한 사진 미리보기
* 사진 분석 방식 선택
* 온디바이스 AI를 이용한 사진 분석
* 분석 결과 확인
* 분석 이력 저장 및 조회
* 분석 이력 삭제
* 분석 결과 공유

## 화면 구성

앱은 다음과 같은 흐름으로 구성할 예정입니다.

```text
타이틀 화면
    ↓
사진 선택 / 촬영
    ↓
사진 확인 및 분석 옵션 선택
    ↓
분석 진행
    ↓
분석 결과
```

사진 선택 화면에서는 이전 분석 결과를 확인할 수 있는 **분석 이력 화면**으로도 이동할 수 있습니다.

## 현재 프로젝트 구조

현재는 본격적인 기능 구현에 앞서 기본적인 프로젝트 구조를 구성한 상태입니다.

현 상태 구조
```text
lib/
├── main.dart
├── app/
│   ├── app.dart
│   ├── routes/
│   │   └── app_router.dart
│   └── theme/
│       └── app_theme.dart
├── core/
├── presentation/
│   └── title/
│       └── title_page.dart
├── domain/
└── data/
```

기능이 추가되면서 사진 입력, 분석, 분석 결과, 이력 등의 화면과 관련 코드가 순차적으로 추가될 예정입니다.

## 사용 기술

* Flutter
* Dart
* FVM
* Git / GitHub

사진 분석 기능에는 ML Kit 등의 온디바이스 AI 기술을 사용할 예정입니다.

## 실행 방법

Flutter 개발 환경이 준비되어 있어야 합니다.

```bash
flutter pub get
flutter run
```

FVM을 사용하는 경우 다음과 같이 실행할 수 있습니다.

```bash
fvm flutter pub get
fvm flutter run
```

## 개발 방향

이 프로젝트에서는 다음 사항을 중요하게 고려합니다.

* 사진 분석을 가능한 한 기기 내부에서 처리
* 원본 사진을 서버로 전송하지 않음
* 분석 이력에는 원본 사진이 아닌 분석 결과를 저장
* 사진 선택 취소나 권한 거부 등의 상황에서도 앱이 정상적으로 동작하도록 처리
* 팀원이 기능별로 나누어 개발하고 이후 하나의 앱으로 통합

## 진행 상태

현재는 프로젝트의 기본 구조를 구성하고 있으며, 이후 화면 UI를 구체화한 뒤 사진 입력 기능부터 단계적으로 구현할 예정입니다.
