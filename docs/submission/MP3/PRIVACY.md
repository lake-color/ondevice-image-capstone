# PRIVACY — 저장하는 것과 저장하지 않는 것

사진 분석 앱(MP3)이 기기에 무엇을 남기고 무엇을 남기지 않는지, 그리고 그 이유를 적은 문서입니다.
내용은 `app/` 소스와 Pixel 9 Pro 에뮬레이터(Android 16)에서 확인한 결과를 기준으로 합니다.

## 원칙

1. 원본 사진은 저장하지 않습니다. 이력에는 분석 결과 텍스트만 남깁니다.
2. 사진과 분석 결과를 서버로 보내지 않습니다. 분석은 기기 안에서만 실행됩니다.
3. 결과가 기기 밖으로 나가는 경우는 사용자가 직접 공유 버튼을 눌렀을 때뿐이며, 그때도 텍스트만 전달합니다.

## 저장하는 것

분석이 끝나면 결과 한 건을 앱 전용 저장소의 `analysis_history.json` 파일에 추가합니다.

| 항목 | JSON 필드 | 예시 | 저장하는 이유 |
|---|---|---|---|
| 이력 ID | `id` | `1794733980786556` | 항목을 구분하고 개별 삭제하기 위해. 생성 시각으로 만든 값입니다. |
| 분석 방식 | `method` | `ocr`, `imageClassification` | 이력 목록에서 어떤 분석인지 표시하기 위해 |
| 결과 제목 | `title` | `인식된 텍스트` | 공유 문구의 첫 줄로 사용 |
| 결과 텍스트 | `content` | 인식한 글자 또는 분류 라벨 | 이력의 본체. 다시 보고 공유하기 위해 |
| 처리 시간 | `durationMicroseconds` | `579308` | 분석에 걸린 시간을 이력에 표시하기 위해 |
| 분석 시각 | `createdAt` | `2026-11-15T09:13:00.786556` | 최신순 정렬과 시각 표시 |
| 신뢰도 | `confidence` | `0.1637`, 텍스트 인식은 `null` | 사물 분류 결과의 확실한 정도 표시 |
| 임시 파일 이름 | `sourceName` | `scaled_49.png` | 결과 모델의 일부로 함께 저장됩니다. 아래 설명 참고 |

- **저장 위치**: 앱 지원 디렉터리(Android `files/`, iOS Application Support)의 `analysis_history.json`. 다른 앱은 접근할 수 없습니다.
- **보관 기간**: 사용자가 이력 화면에서 삭제하거나 앱을 삭제할 때까지입니다.
- **삭제 방법**: 이력 화면의 **삭제** 버튼으로 항목을 하나씩 지웁니다. 삭제하면 파일에서도 즉시 사라지며 복구할 수 없습니다.

### 주의할 점

- **결과 텍스트에는 사진 속 글자가 그대로 들어갑니다.** 문서를 찍으면 그 안의 이름이나 번호도 텍스트로 저장됩니다. 원본 사진은 남지 않지만 내용이 민감하다면 해당 이력을 삭제해야 합니다.
- **`sourceName`은 사용자가 붙인 파일 이름이 아닙니다.** 사진 선택기가 임시 사본에 붙인 이름(`scaled_49.png`, `scaled_<임의 문자열>.jpg`)이며 화면에는 표시하지 않습니다. 경로는 포함하지 않습니다.

## 저장하지 않는 것

| 항목 | 저장하지 않는 이유 | 코드에서 확인할 곳 |
|---|---|---|
| 원본 사진 파일(이미지 데이터) | 사진에는 얼굴, 장소, 문서 전체가 담길 수 있어 결과 텍스트보다 훨씬 민감합니다. 분석이 끝나면 더 필요하지 않습니다. | `AnalysisResult.toJson`에 이미지 필드가 없음 |
| 사진 경로 | 경로가 남으면 나중에 사진을 다시 찾아갈 수 있습니다. | `imagePath`는 `toJson`에서 제외. 주석: "never serialized into history" |
| 썸네일·축소본 | 축소본도 원본의 일부입니다. | 이력 카드는 텍스트만 표시(`history_page.dart`) |
| 촬영 위치·기기 정보 등 사진 메타데이터(EXIF) | 분석에 필요하지 않습니다. | 방향 보정을 위해 읽기만 하고 저장하지 않음(`mobilenet_classifier.dart`) |
| 계정·기기 식별자 | 로그인이 없고 사용자를 구분할 필요가 없습니다. | 인증·분석 도구 패키지가 `pubspec.yaml`에 없음 |
| 사용 기록·통계 | 수집하지 않습니다. | 위와 같음 |

이전에 저장된 이력을 읽을 때도 `imagePath`는 복원되지 않습니다. 그래서 이력에서 연 결과에는 사진이 없습니다.

## 분석 중에만 잠깐 존재하는 것

사진을 고르면 OS의 사진 선택기가 앱 캐시 폴더에 **임시 사본**을 만들어 넘겨줍니다. 앱은 갤러리의 원본에 직접 접근하지 않습니다.

- 임시 사본은 미리보기와 분석에만 쓰입니다.
- 다른 사진으로 바꾸거나 사진 선택 화면을 나가면 앱이 임시 사본을 삭제합니다(`ImageInputService.discard`).
- Android에서는 선택기가 사본을 두 개(처음 복사본과 `scaled_` 사본) 만들기 때문에 둘 다 지웁니다.
- 갤러리에 있는 사용자의 원본 사진은 건드리지 않습니다.

에뮬레이터에서 확인한 결과:

| 시점 | 앱 캐시 폴더 |
|---|---|
| 사진을 고른 직후 | `scaled_49.png`, `<임의 폴더>/49.png` |
| 다른 사진으로 바꾼 뒤 | 새 사진의 사본만 남고 이전 사본 2개는 삭제됨 |
| 사진 선택 화면을 나간 뒤 | 비어 있음 |

**한계**: 화면을 나가기 전에 앱이 강제 종료되면 임시 사본이 캐시에 남을 수 있습니다. 캐시는 OS가 저장 공간이 부족할 때 정리하며, 사용자가 기기 설정에서 직접 지울 수도 있습니다.

## 기기 밖으로 나가는 것

| 경로 | 내용 |
|---|---|
| 서버 전송 | 없습니다. 앱 코드에 사진이나 결과를 보내는 네트워크 호출이 없습니다. |
| 분석 | 기기 안에서만 실행됩니다. 비행기 모드에서도 동작합니다(MP2에서 검증). |
| 결과 공유 | 사용자가 **결과 공유하기**를 누르면 OS 공유 시트가 열립니다. 전달되는 것은 결과 텍스트(제목, 내용, 신뢰도, 분석 시간)뿐이며 사진은 포함하지 않습니다. 받는 앱은 사용자가 고릅니다. |
| 클라우드 백업 | Android는 `android:allowBackup="false"`로 꺼 두어 이력이 계정 백업에 올라가지 않습니다. |

공유 문구 예시:

```text
인식된 텍스트
온디바이스 사진 분석
회의록 2026년 11월 15일
On-device OCR Test 123
사진은 서버로 보내지 않습니다.
분석 시간: 579ms
```

공유한 뒤의 텍스트는 받은 앱의 정책을 따르며, 이 앱이 회수할 수 없습니다.

## 권한

| 권한 | 용도 | 요청 시점 |
|---|---|---|
| 카메라 | 분석할 사진 촬영 | 사용자가 "카메라로 촬영"을 고를 때 |
| 사진 보관함(iOS) | 분석할 사진 선택 | 사용자가 "갤러리에서 선택"을 고를 때 |

Android 갤러리는 시스템 사진 선택기를 사용해 저장소 권한이 필요 없고, 사용자가 고른 사진 한 장만 전달됩니다.
위치, 연락처, 마이크 권한은 사용하지 않습니다.

## 확인하지 못한 것

- iOS와 실기기에서는 실행하지 않았습니다. iOS의 임시 사본 삭제와 저장 위치는 코드 기준 설명이며 실제 동작은 검증하지 않았습니다.
- iOS에서는 Application Support 폴더가 기본적으로 기기 백업(iCloud·Finder)에 포함됩니다. 이력을 백업에서 제외하는 처리는 하지 않았습니다.
- Android 12 이상의 기기 간 직접 전송(새 기기로 옮기기)에서 이력이 제외되는지는 확인하지 않았습니다.
- Google ML Kit 라이브러리가 자체적으로 수집하는 사용 통계가 있는지는 확인하지 않았습니다. 앱은 사진이나 결과를 ML Kit 서버로 보내지 않습니다.
